# 댓글 기반 1:1 채팅방 생성 설계

## 목표

피드의 타인 댓글에서 댓글 작성자와 1:1 채팅을 시작할 수 있게 한다. 동일한 두 사용자가 여러 댓글이나 반대 방향의 요청을 통해 진입하더라도 하나의 `DIRECT` 채팅방을 재사용한다.

## API 계약

인증된 사용자가 다음 엔드포인트를 호출한다.

```http
POST /api/v1/comments/{commentId}/chat-room
Authorization: Bearer {accessToken}
```

요청 본문은 없다. 성공 시 기존 공통 envelope로 응답한다.

```json
{
  "ok": true,
  "data": {
    "id": "chat-room-uuid",
    "type": "DIRECT",
    "name": null
  },
  "error": null
}
```

## 백엔드 동작

1. `commentId`에 해당하는 삭제되지 않은 댓글을 조회한다.
2. 댓글이 없거나 삭제된 경우 `404 RESOURCE_NOT_FOUND`를 반환한다.
3. 요청자와 댓글 작성자가 같으면 `400 VALIDATION_ERROR`를 반환한다.
4. 두 사용자 UUID를 정렬해 기존 `ChatRoom.direct_key` 형식의 고유 키를 만든다.
5. 같은 `direct_key`의 방이 있으면 참가자 정보를 확인하고 그 방을 반환한다.
6. 방이 없으면 `type=DIRECT`, `name=null`인 방과 두 `ChatParticipant`를 같은 트랜잭션에서 생성한다.
7. 성공 응답은 항상 동일한 `{id, type, name}` 구조를 사용한다.

직접방 키 생성과 방 조회·생성 로직은 채팅 모듈에 둔다. 편지 매칭에서 사용하는 직접방 생성도 같은 helper를 사용하도록 정리해 댓글 기능과 편지 기능이 서로 다른 중복 정책을 갖지 않게 한다.

## Android 동작

- `FeedApiService`에 `POST comments/{commentId}/chat-room`을 추가한다.
- 응답 DTO는 UUID 문자열 `id`, `DIRECT` 타입, nullable `name`을 가진다.
- `FeedApi`는 댓글 ID를 받아 채팅방 ID를 반환하는 함수를 제공한다.
- 타인의 댓글 메뉴에 `채팅하기`를 표시한다. 자기 댓글에는 표시하지 않는다.
- 요청 성공 후에만 반환된 방 UUID로 기존 채팅방 화면에 이동한다.
- 실패하면 현재 피드 상세 화면을 유지하고 재시도 가능한 오류 메시지를 표시한다.

## 오류와 일관성

- 인증 누락 또는 만료는 기존 인증 계층의 `401` 계약을 따른다.
- 자기 댓글은 잘못된 작업으로 처리해 `400 VALIDATION_ERROR`를 반환한다.
- 삭제되었거나 존재하지 않는 댓글은 리소스 존재 여부를 노출하지 않는 기존 규칙대로 `404 RESOURCE_NOT_FOUND`를 반환한다.
- `direct_key`의 데이터베이스 고유 제약을 유지한다. 순차 중복 요청은 조회 결과를 재사용하고, 생성 경쟁이 발생해도 최종적으로 하나의 방만 유효해야 한다.
- 채팅방 생성과 참가자 추가는 한 트랜잭션으로 커밋한다.

## 검증

백엔드 테스트는 다음을 확인한다.

- 인증된 타인 댓글 요청이 `DIRECT` 방을 생성한다.
- 같은 댓글 재요청이 같은 방 UUID를 반환한다.
- 동일한 사용자 쌍의 다른 댓글과 반대 방향 요청도 같은 방을 반환한다.
- 자기 댓글, 삭제 댓글, 없는 댓글, 인증 누락이 각각 정의된 오류를 반환한다.
- 생성된 방에 정확히 두 참가자가 존재한다.
- OpenAPI에 경로와 성공 응답 구조가 포함된다.

Android 테스트는 정확한 HTTP method/path, Bearer 적용, 응답 envelope 변환, 성공 후 화면 이동용 방 ID 전달, 실패 시 이동하지 않는 동작을 확인한다. 전체 백엔드 테스트, Android 단위 테스트와 debug APK 빌드를 최종 게이트로 사용한다.

## 범위 제외

- 채팅 메시지 전송·WebSocket 계약 변경
- 채팅방 목록 디자인 개편
- 차단 사용자, 친구 관계, 알림 정책 추가
- 운영 환경용 고급 재시도 또는 분산 잠금
